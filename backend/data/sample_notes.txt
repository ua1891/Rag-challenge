Introduction to Machine Learning

Machine learning is a subset of artificial intelligence that allows systems to learn patterns from data instead of being explicitly programmed with rules. There are three main types: supervised learning, unsupervised learning, and reinforcement learning. Supervised learning trains a model using labeled data, where each example has a known correct answer, and is commonly used for tasks like spam detection and image classification. Unsupervised learning works with unlabeled data and is often used for clustering and anomaly detection, where the goal is to discover hidden structure without predefined categories. Reinforcement learning trains an agent through trial and error, using rewards and penalties to improve its behavior over time, and has been used successfully in game-playing AI and robotics.

Overfitting and Generalization

A key challenge in machine learning is overfitting, where a model learns the training data too well, including its noise and random fluctuations, and as a result performs poorly on new, unseen data. Generalization refers to a model's ability to perform well on data it has never seen before. Techniques to reduce overfitting include using more training data, simplifying the model, applying regularization, and using cross-validation to evaluate performance more reliably.

What is RAG?

Retrieval-Augmented Generation, or RAG, is a technique that combines a language model with a retrieval system. Instead of relying only on what the model learned during training, RAG retrieves relevant pieces of external documents at question time and provides them to the model as context. This allows the model to answer questions about specific documents it has never seen before, and reduces hallucination since the model is grounded in real retrieved text rather than guessing from memory.

Vector Embeddings

An embedding is a way of representing text as a list of numbers, called a vector, that captures the meaning of the text. Pieces of text with similar meaning end up with vectors that are close to each other in this numerical space, even if they use completely different words. This property is what makes it possible to search by meaning instead of by exact keyword matching. Embeddings are typically generated by a specialized model trained specifically to produce these vector representations.

Vector Databases

A vector database is a specialized database designed to store embeddings and search them efficiently based on similarity rather than exact matches. Instead of looking for an exact value like a traditional database, a vector database finds the vectors that are mathematically closest to a given query vector, using measures like cosine similarity. This allows a system to quickly find the most relevant pieces of text out of thousands or millions of stored chunks, which is essential for making retrieval fast enough to use in a real application.

Chunking Strategy

Before documents can be embedded and stored, they need to be split into smaller pieces called chunks, since embedding an entire long document as a single vector loses too much detail to be useful for precise retrieval. Chunk size involves a trade-off: chunks that are too small may lack enough context to be meaningful on their own, while chunks that are too large may contain multiple unrelated ideas, making the resulting vector representation less precise. Overlapping chunks, where each chunk shares some text with the one before it, help prevent important information from being awkwardly split across a chunk boundary.
Prompt Grounding

Grounding refers to instructing a language model to base its answer strictly on the provided context, rather than its own general knowledge. A well-grounded prompt explicitly tells the model to only use the retrieved text to answer, and to say it does not know rather than guessing if the answer is not present in that text. This is one of the most effective ways to reduce hallucination in a retrieval-augmented system, since it removes the incentive for the model to fill gaps with plausible-sounding but unverified information.
